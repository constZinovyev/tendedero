# Записная книжка в Tendedero

Что это, как пользоваться и как всё устроено. Написано 17 октября 2026 для
будущих сессий: прочитайте это перед работой над книжкой.

## Что получилось

- На верёвке Tendedero висит льняная тетрадь на прищепке, сбоку торчат цветные
  стикеры разделов. Её можно двигать вдоль верёвки, от ветра она качается.
- **Потянуть вниз** — тетрадь срывается с прищепки, её можно положить в любое
  место экрана. Там она лежит, даже когда верёвка спрятана. Поднести к верёвке —
  снова повиснет. Меню: Notebook → «Hang it back on the line».
- **Клик или ⌥⌘N** — обложка слетает и в 3D раскрывается в разворот:
  слева оглавление раздела (список страниц, «+ новая страница»), справа сама
  страница. Стикеры справа переключают разделы, ‹ › листают страницы, с шелестом.
- **Закрыть**: Esc, ⌥⌘N или клик мимо книжки.
- Страница — это Markdown: `# заголовки`, `- [ ] задачи` (клик по скобкам ставит
  галочку), `**жирный**`, `*курсив*`, ссылки, вставка скриншотов (⌘V или
  перетаскиванием). Пустая страница, с которой ушли, удаляется сама.
- **Пароль**: книжка зашифрована. Первый клик просит придумать пароль (от 8
  символов). Потом открывается **пальцем (Touch ID)** или паролем.
  **Пароль нельзя восстановить** — он хранится только у владельца.
- Запирается: при блокировке экрана, сне, смене пользователя и после закрытия
  книжки (по умолчанию через 5 минут; Notebook → «Lock after closing»).

Ещё в этой же работе:
- фото и тетрадь можно увести почти к краю экрана (14 pt от края);
- в меню есть ползунок «Photo size» (60–100%);
- исправлены «лесные» обои на одном из рабочих столов: экран блокировки
  оставил свою картинку в настройках обоев. Теперь `LockScreen.mended` сам
  заменяет такие остатки на обычные обои.

| Ядро: хранение, шифрование, git | `Sources/NotesCore/` |
| Вид: верёвка, книжка, пароль | `Sources/Tendedero/Notes/` |
| Тесты ядра | `Tests/NotesCoreTests/`, запуск `scripts/test.sh` |

Другой путь к заметкам: `defaults write app.tendedero.Tendedero NotebookPath <путь>`
(и `NotebookRemote`). Переменная `NOTES_ROOT` — для пробных запусков на чужой папке.

`~/projects/tendedero_personal_notes` — первый прототип отдельным приложением,
больше не нужен; туда ничего не пушилось.

## Как устроено шифрование

В репозитории заметок лежит только это:

```
vault.json             главный ключ, запечатанный ключом из пароля
sections.sealed        названия, порядок и цвета разделов
pages/<хеш>.sealed     страница: id, раздел, текст
files/<хеш>.sealed     картинка или файл
.gitattributes, README.md
```

- Главный ключ: случайные 256 бит. Из пароля делается ключ через PBKDF2-SHA256.
  Число раундов подбирается так, чтобы одна попытка шла около 0.7 с
  (не меньше 310 000). Этим ключом главный ключ запечатан AES-256-GCM.
  Смена пароля перепечатывает только `vault.json`.
- Из главного ключа через HKDF выводятся два ключа: для шифрования и для имён файлов.
- Каждый файл шифруется отдельно, AES-256-GCM. Имя файла входит в шифр как
  связанные данные: подменённый или переставленный файл не читается.
- Имена файлов — HMAC от id страницы (или от хеша содержимого для картинок).
  Ни даты, ни названия не видны. Коммиты называются «Заметки обновлены».
- Страницы расшифровываются только в памяти. Файл, открытый в другой программе
  (двойной клик по картинке), пишется во временную папку с правами 0700/0600,
  а при блокировке она стирается.
- Цвета стикеров хранятся открыто в настройках (`notebookTabColors`), чтобы
  закрытая тетрадь была цветной. Они ничего не раскрывают.

**Touch ID** (`Fingerprint.swift`): в Secure Enclave создаётся ключ P-256 с
доступом `biometryCurrentSet`. Главный ключ запечатан к нему через ECDH и HKDF
плюс AES-GCM. Пароль нигде не хранится. Новые отпечатки делают ключ
недействительным — тогда снова пароль. Без платной подписи Apple это работает,
потому что CryptoKit не требует entitlements.

**Синхронизация** (`Sync.swift`): коммит через 30 секунд тишины и при закрытии
книжки, push в фоне, pull раз в 5 минут. При конфликте побеждает локальная
версия, чужая остаётся в истории git.

## Как читать заметки без Tendedero

Сейчас — только через Tendedero: склонировать репозиторий, указать путь,
ввести пароль. Отдельной команды для расшифровки ещё нет (см. планы).

## Сборка и проверка

- `scripts/run-dev.sh` — собрать и перезапустить (кнопка из `CLAUDE.local.md`).
- `scripts/test.sh` — тесты ядра (24 штуки: хранение, git, шифрование, Touch ID-обёртка).
  Swift Testing из Command Line Tools требует флагов; скрипт их подставляет.
- Внешний вид проверялся без захвата экрана: вид временно рисуется в PNG
  (`ImageRenderer` для SwiftUI, `cacheDisplay` для AppKit) через временную
  переменную окружения в `main.swift`. Потом это удаляется. `SecureField` на
  таких снимках выглядит жёлтой заглушкой — это нормально.
- Пользователь не любит, когда сессия берёт экран под управление.
